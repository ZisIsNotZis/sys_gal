# Sys Gal 🧠

English | [简体中文](README.zh-CN.md)

An experimental Chinese narrative-simulation workspace. It studies autonomous
characters, information boundaries, and reproducible story trajectories through
versioned scenario and harness work.

## Quickstart

Read [AGENTS.md](AGENTS.md) before running provider-backed work. The primary
experiment is under [`契约失效时请勿喂猫/`](契约失效时请勿喂猫/); its local README
defines the available checks and prerequisites.

## Status and future

This is an evolving research prototype, not a finished game or claim of human
story quality. The future goal is a reproducible narrative laboratory where
character behavior, knowledge, failures, and causal continuity can be inspected.

Issues and PRs are welcome. Agents may help investigate and document; maintainers
review and merge.
