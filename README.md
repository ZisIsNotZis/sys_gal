# Sys Gal 🧠

English | [简体中文](README.zh-CN.md)

An experimental Chinese narrative-simulation workspace. It studies autonomous
characters, information boundaries, and reproducible story trajectories through
versioned scenario and harness work.

## Where to start

- [AGENTS.md](AGENTS.md) — repo-wide agent working policy; read before

- [`契约失效时请勿喂猫/`](契约失效时请勿喂猫/) — the primary experiment. Start at

  line's [roadmap](契约失效时请勿喂猫/v5/docs/V5-ROADMAP.md) (milestones, story ladder).

## Status and future

This is an evolving research prototype, not a finished game or claim of human
story quality. The current line is v5 (`契约失效时请勿喂猫/v5`); the goal is a reproducible
narrative laboratory where character behavior, knowledge, failures, and causal
continuity can be inspected. See the main line's
[roadmap](契约失效时请勿喂猫/v5/docs/V5-ROADMAP.md) for where it stands.

Issues and PRs are welcome. Agents may help investigate and document;
maintainers review and merge.
