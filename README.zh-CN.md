- [AGENTS.md](AGENTS.md) — 仓库级 agent 工作政策；运行 provider 实验前先读。
- [`契约失效时请勿喂猫/`](契约失效时请勿喂猫/) — 主要实验。先读它的

- [docs/archive/](docs/archive/) / [docs/reference/](docs/reference/) — 历史与非权威资料。

## 状态与未来

这是持续演进的研究原型，不是完成的游戏，也不宣称具有人类级故事质量。当前
活动线是 v4；未来希望成为可复现的叙事实验室，能够检查角色行为、知识、失败
与因果连续性。当前进度见项目 [ROADMAP](契约失效时请勿喂猫/ROADMAP.md)。

欢迎 Issue 和 PR。代理可以协助调查和文档工作；维护者负责审核与合并。
