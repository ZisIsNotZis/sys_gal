# Sys Gal 🧠

[English](README.md) | 简体中文

这是一个中文叙事模拟实验工作区，研究自主角色、信息边界和可复现故事轨迹。

## 快速开始

运行 provider 相关实验前请先阅读 [AGENTS.md](AGENTS.md)。主要实验位于
[`契约失效时请勿喂猫/`](契约失效时请勿喂猫/)，其中的 README 说明检查方式和前置条件。

## 状态与未来

这是持续演进的研究原型，不是完成的游戏，也不宣称具有人类级故事质量。未来希望
成为可复现的叙事实验室，能够检查角色行为、知识、失败与因果连续性。

欢迎 Issue 和 PR。代理可以协助调查和文档工作；维护者负责审核与合并。
