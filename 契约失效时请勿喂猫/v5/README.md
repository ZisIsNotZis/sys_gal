# v5 — 重写的世界模型

v5 不是 v4 的续集，是同一实验室的**重造**：引擎只保留十条原始项，世界由库里的概念表达，故事只是使用它们的一份种子。规格在 `docs/`，代码在 `engine/` 与 `library/`，故事在 `stories/`。

## 现在能跑什么

- **M1**：引擎骨架（实体、状态、包含、时间、事件、感知投递、心智、意愿、规则、命名解析）+ 《末班车》三条脚本路径。
- **M2**：库 v0 —— 16 个动词（读写、拿放、给、开、敲、走、等、细看、擦、复写、开锁、认字、说话）+ 《借条》四条脚本路径。**认字只靠知识**：纸只给墨色与字形，谁写的要靠人自己认。

`transcript.md` 故事视图、`context.md` 每回合的完整上下文与模型原始工具调用、`run.json`+`events.jsonl` 可重放记录。
第一份对照实验的读法见 `docs/V5-M3-PILOT.md`。

## 四条反向门（M1 的验收）

1. **摸与读不留痕**：读只写进读者的记忆，被读的纸一点都不变。
2. **渲染没有来源**：轨迹里不出现作者、写于、读者；纸只带着它上面写的字。
3. **指称不到时可行动**：说一个不存在的地方，得到"眼前能看见什么"，而不是一句"找不到"。

另有第四条：**轨迹只叙述有人感知到的事**，世界事件必须写明"谁感到"。

## 智能体表面

每个角色每回合的上下文由引擎生成并逐回合记录：**一眼**（时间、所在、眼前、手里）、**最近**（他自己感知到的几条）、**知道的事**（他相信的，可能错）、以及只在本人记忆里按字面检索的**回想**。纸上"有字"是看一眼就知道的，"写了什么"必须**读**——所以"读过"是有后果的动作，而不是自动知道的。

## 目录

```text
v5/
├── docs/       # 原始集、三层、场景清单、路线图（真理）
├── engine/     # 十条原始项；不认识任何故事名词

└── tests/      # 引擎、门禁、重放、故事验收
```

## 生长的纪律

- 概念进库只有两条路：**被两支以上故事用到**，或**一次消掉一整类绕路**；否则留在种子层做局部覆盖。M1 只有一支故事，所以 `v5_lint.py` 把孤儿检查记为"待补"，M2 起用 `--strict` 变成失败。
- 下沉细节要付四件套：失败的场景、规则、渲染、测试。
- 引擎里出现故事名词、提示里出现状态键、种子里出现逻辑，都算越界。
