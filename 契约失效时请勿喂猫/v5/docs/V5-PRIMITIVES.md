# V5 原始集（引擎拥有的全部概念）

本文件是 V5 引擎的**唯一概念权威**。库概念、种子、检查器都从这十条派生；引擎源码里出现这十条以外的世界名词即为耦合缺陷。

## 1. 边界

引擎只做三件事：**解析**（指称→实体、话→意愿）、**编排**（时间推进、排程、回合、检查点）、**原始项**（本文件）。它不认识"纸""写""签字""校园"，也不认识任何故事里的人和物。

## 2. 原始集一览

| # | 名称 | 一句话 |
| --- | --- | --- |
| P1 | 实体 | 有稳定身份的东西，人也算 |
| P2 | 状态 | 实体上的结构化物理事实（键→值） |
| P3 | 包含 | 实体在某个容器或地点里，一棵树，无环 |
| P4 | 时间 | 单调时钟 + 到点触发 + 动作耗时 |
| P5 | 事件 | 不可变的状态变化记录，带因果 |
| P6 | 感知投递 | 一条事实经某个通道进入某个心智 |
| P7 | 心智 | 能积累感知、持有知识、提出意愿的实体 |
| P8 | 意愿 | 心智提出的一次改变尝试，合法性由规则裁 |
| P9 | 规则 | 从（意愿 + 物性 + 状态 + 时间）到原子效果的声明式映射 |
| P10 | 命名解析 | 心智如何指称实体：名字、别名、描述、指代、序数 |

## 3. 逐条

### P1 实体

- **是什么**：一个身份号（单调递增、永不复用）+ 一个扁平的类型标签。仅此。
- **为什么不可约**：其余九条都是"关于某个东西"的；没有身份，状态无处归属、事件没有主语、指称无处落地。身份还必须是稳定的，否则重放与检查点无法对齐。
- **操作**：创建、销毁、按身份取状态。
- **不含**：不含名字（那是 P10 与语言）、不含类型继承（类型只是标签，分类学是库）。

### P2 状态

- **是什么**：`实体 → {键: 值}`。键的语义与值的类型由**库**声明，引擎只负责存取与事务性。
- **为什么不可约**：状态是"在没有观察者时仍然存在的物理事实"的唯一载体。所有可感知的东西都是状态的一次投影。
- **操作**：读键、写键、删除键；一次意愿内的全部写入必须原子生效或全部不生效。
- **不含**：不含历史（历史是 P5）、不含解释（"这是一份说明"是知识，不是状态）。

### P3 包含

- **是什么**：`实体 → 父（地点或容器）`，构成一棵树；地点也是实体。人可以在地点里，物可以在地点里或某个容器里。
- **为什么不可约**：拿、放、递、翻找、装、搬全部建立在它之上；写成状态键也"能凑"，但那样每条规则都要自己重实现树不变式、环检测与共同在场计算——这不是抽象，是把不变式复制到每一处。
- **操作**：移动、列出直接子项、求共同在场、判断可达。
- **不含**：不含距离与路径（路程是库概念在地点图上的时间代价）、不含"隐藏"（可见性是状态键）。

### P4 时间

- **是什么**：单调时钟 + 排程表（到点触发）+ 动作可带耗时。
- **为什么不可约**：没有排程的未来，"期限、等待、旅途、睡着、明天八点"全都无法表达，引擎会退化成回合顺序的奴隶。
- **操作**：读现在、排一个到期效果、推进到下一个到期点、给动作计时。
- **不含**：不含日历语义（工作日、节日是库/种子的事实）、不含随机（随机是 `(种子, 事件号)` 的纯函数，见 §5）。

### P5 事件

- **是什么**：`{事件号, 时间, 种类, 主体, 客体, 状态增量, 因果}` 的不可变记录。**它是世界的账本，不是任何人的知识。**
- **为什么不可约**：重放、审计、记忆、因果解释四件事都要它；没有它，状态变化无法解释，检查点无法续跑，运行无法复核。
- **操作**：追加、按条件遍历、重放。
- **不含**：不含可感知性。事件永不直接进入任何心智；进心智的只有 P6 投递的渲染结果。

### P6 感知投递

- **是什么**：一条"某事件经某通道到达某心智"的投递，附带**渲染文本**（该心智实际感知到的内容）与保真度。
- **为什么不可约**：这是世界真相与角色知识之间唯一的闸门。抽掉它，模型就是全知的——v4 里"批注带作者""全局通知"正是这道闸门缺失时的样子。
- **操作**：投递、计算通道与范围、记录"谁能感知到"。
- **不含**：不含内容的解释（渲染文本里只有物理：字、墨色、声音、动作；不含作者、不含时间戳、不含"谁读过"）。

### P7 心智

- **是什么**：带记忆与知识的实体。记忆是感知投递的累积；知识是概念、实体、关系、程序（谁是谁、什么字是谁的、手续怎么走）；另有当前意愿与在飞动作。
- **为什么不可约**：人与物的唯一分界，也是"读只改变读者"这条规则落地的地方。
- **操作**：写记忆、检索记忆、增删知识、挂起与恢复意愿。
- **不含**：不含"事实"——记忆可以是错的、缺的、被后来的话污染的；这由库的保真度规则决定，引擎只负责存与取。

### P8 意愿

- **是什么**：心智提出的 `(动词, 已解析的客体, 期望)`。引擎按规则判合法，然后要么产生效果与事件，要么产生**拒绝回执**（为什么不成、眼前可行的有哪些）。
- **为什么不可约**："尝试"与"结果"必须分开，否则"想拿却被锁住""想说话但人已经走了"这类最平常的人类经验无法表达，错误也无法被角色理解。
- **操作**：构造、校验、执行、拒绝、被中途打断。
- **不含**：不含动词表（动词是库概念，见 `V5-LAYERS.md`）。

### P9 规则

- **是什么**：`when`（对物性、状态、包含、持有、知识的条件）+ `do`（原子效果）+ `cost`（时间）+ `render`（参与者看到的）+ `fail`（失败与可行清单）。**纯函数**：只依赖状态、时间与 `(种子, 事件号)`。
- **为什么不可约**：物性如果写进代码，引擎就认识故事了；规则是"物理与制度住在库里"的唯一形式。
- **原子效果封闭集**：`set_state`、`transfer`（含搬移）、`create`、`destroy`、`deliver`（感知）、`schedule`（未来效果）、`advance_time`、`remember`。
- **不含**：不含任意代码、不含概率分支（用 `(种子, 事件号)` 取伪随机）、不含把作者意图写进 `when`。

### P10 命名解析

- **是什么**：把一个心智说出的指称（名字、别名、描述、指代、序数）解析为一个实体，**只允许用该心智此刻能感知与已知的东西**。歧义时按确定性规则挑选并**说出来**，或者回问；完全无解时返回"这里现在有什么"的可行动清单。
- **为什么不可约**：它同时是接口和世界事实——一个人能怎么称呼一样东西，取决于他知道什么。v4 的"通讯录不对称""305 不是你知道的地方""指代歧义"都是把它当 UI 细节的代价。
- **操作**：解析、消歧、回问、列出可指称项。
- **不含**：不含命名策略（别名的来源、称呼的礼貌层级都是库/种子）。

## 4. 由原始项组合的概念（全部属于库）

| 概念 | 组合 |
| --- | --- |
| 写 | P2 铭文键 + P9 表面接受某手段 + P6 读到的人才看见 |
| 读 | P6 + P7（**不改物件**） |
| 说 | P6 + 通道范围 + P7 |
| 拿/放/给 | P3 + P4（耗时）+ P6 |
| 走 | P3 + P4（路程） |
| 复制 | P1/P2 + P9（副本带来源痕迹） |
| 锁 | P2 + P9（钥匙匹配） |
| 吃/喝 | P2（份数）+ P4 |
| 等/睡 | P4 + P6（感知边界） |
| 承诺 | P4 + P7 + P6（到点把提醒投递给某人心智） |

## 5. 四条守则（可检查）

1. **引擎永不凭空造痕**：任何状态只能由某条声明过的规则写入。没有规则声明的交互，什么都不留。
2. **每个状态键必须成对给出渲染**：一条角色永远看不见的状态就是隐藏的魔法。lint 要求键与渲染模板成对；渲染可有一眼与细看两档，而**内容（纸上写了什么）永远只能由有代价的动作取得**，不随"看一眼"白给。
3. **事件不可感知**：渲染里不许出现事件层元数据（作者、时间戳、读者、因果）。反向测试专门抓这条。
4. **规则是纯函数**：不许读墙钟、不许 IO、不许外部随机。重放逐字节一致是可审计性的前提。

## 6. 分辨率常数

**世界的事实分辨率 = 一个用心观察的普通人，不带仪器、一眼或一次细看能注意到的东西。** 字迹、折痕、撕口、破损、湿痕、气味、谁的衣服湿了、谁手里攥着什么，都在此之内；指纹、笔压、纤维、墨水的化学成分，都在此之外。

这不是能力上限的说明，而是**建模契约**：越过这条线的需求，要么改成"某个表面声明了浮灰/水痕"这种通用状态，要么明确写进非目标。

## 7. 非目标

生理需求（饿、渴、睡的资源化）、经济与货币、取证级痕迹、多用户与联网、图形界面、重造时间与调度、为对称而建的库概念。

## 8. 暂缓决定

- 地点是否与物完全同类（现在：是，地点只是库定义的实体类型）。
- 记忆保真度是引擎字段还是库规则（现在：引擎保留字段，取值由库定）。
- 多规则同时适用时的确定性排序：现在一个动词只有一条规则，还没有这个问题；等第一次出现两个规则争同一个动作时再定。
- 动作的中途打断：现在只有"耗时"，没有在飞动作与打断（S3 的截止时间会逼出它）。

## 9. 新增原始项的门

一个提案要成为第十一条，必须**同时**过三关：①现有十条无法组合出它而不让每个使用者重复实现同一不变式；②它是解析或编排层需要的，而不是某个世界的物理；③它不携带任何故事含义。三关任一不过，它就是库概念。
