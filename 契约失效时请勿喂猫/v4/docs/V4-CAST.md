# v4 两层演员制：MC / NPC / 匿名路人

Design truth for the two-tier cast and the enriched world. Decided 2026-09-04.
阻塞/唤醒/心跳的引擎语义 SSOT 见 `V4-ENGINE.md` §3。

## 1. 角色分层

- **MC（主角）**：事件驱动 + 空闲心跳（默认 30 分钟无事件则醒，见 V4-ENGINE
  §3）、完整会话记忆、有秘密、会疼。
  现有三角色（陈默、林瑶、唐小岚）保持 MC。
- **NPC（常驻配角）**：**事件驱动**，不活在钟表里。被唤醒时拿一次导演简报，
  出 1~N 个动作，睡下时本次经历压入 KB 机制（与 MC 同机制，含 person=self
  身份行、todo、reminder；**无独立滚动摘要**——旧机制已废除，见
  V4-AGENT-INTERFACE §5）。MC 视角与 MC 完全同构，不可分辨；trace 里打
  `role: npc` 标记（仅供分析）。
- **匿名路人（extra）**：**对话期生命周期**。场景需要“人”而没有合适的常驻角色时，
  引擎按**该地点的路人池**（身份碎片按场景配置：档案室→值班同学/来访校友；
  食堂→打饭阿姨/同桌学生；咖啡馆→店员/熟客；夜市→摊主；校园→学生。不会在
  学校遇到“随机店主”，也不会在酒吧遇到“随机学生”）现场生成，随机中文姓名。
  生命周期覆盖整段对话：可多轮往返，期间有**会话内记忆**（记得刚才说了什么）；
  对话自然结束（路人离开/MC 离开/闲置超时）才销毁——**销毁后零记忆**。
  路人池带稀有度：大概率是普通路人（只知道地点常识），**小概率遇到“恰好知道
  更多”的信息者**（与角色/地点相关的世界事实）——勤奋反复搭话的 MC 会遇到
  他们，这是勤奋的回报，不是剧情开关。

## 2. NPC 唤醒触发器

1. **被点名**：被说话/收消息/被敲门——必醒。
2. **导演节拍**：排程拍点（周日妈妈的催婚电话、饭点食堂大妈、公告栏更新）。
3. **大事涟漪**：冲突升级或公开事件波及（驱逐夜若有宿管 NPC，陈默会被真赶走）。
4. **冷清检测**：某地点 ≥2 名 actor、连续 K 个 tick 无 speech、近期无排程事件
   → 唤醒一个在场 NPC 找话头。设**每小时唤醒预算**，防止检测器变成烧钱机器。

## 3. 知识边界与导演简报

NPC 唤醒时的上下文 = 人设 + 世界知识摘要 + MC 公开行为摘要 + 当前场景快照 +
导演简报。边界：

- **知道**：全部世界事实（文档、历史、关系网）、MC 的公开行为与对话、
  排程表（未来事件，用于铺垫暗示，**不许剧透**："下周台风纪念活动你准备好了吗"
  可以，"明下午你们会吵架"不行）。
- **不知道**：MC 的私有状态与心声（inner）。专业演员不泄密的保障是"根本不知道
  自己不该知道的事"——读到心就会演穿帮。
- **导演目标**（写进简报，不写进人设）：把故事推向有趣处——撮合、递台阶、
  制造巧合、施压、起哄；执行时全部自然化，MC 不能看出导演的手。

## 4. NPC 恋爱政策

一律**自然 deflection**：NPC 自带不可攻设定（异地恋、已婚、师生身份等），
把 MC 的感情引回 MC 之间的线。简报要求：deflect 必须像真人（含糊、转移、
自嘲），禁止直说设定（"我不会喜欢你"等于穿帮）。

## 5. 首版 NPC 班底（社会功能各一）

| NPC | 功能 | 唤醒场景 |
|---|---|---|
| 宿管阿姨 | 权威+执法（补驱逐夜的缺口） | 宿舍违规、夜归 |
| 食堂大妈 | 情报+人情（多给一勺菜） | 饭点 |
| 辅导员 | deadline 压力源 | 节点前后 |
| 班长 | 传话+组织 | 群体事务 |
| 陈默妈（远程） | 催婚/关心 | 周日电话 |
| 林瑶室友 | 闺蜜+起哄主力 | 宿舍夜谈 |
| 下棋大爷 | 世界观输出 | 中庭/公园 |

## 6. 世界加厚（给 NPC 抓手、给 MC 去处）

- **新地点**：食堂、小卖部、操场、图书馆、男生宿舍/女生宿舍（宿舍拆分并加
  边界规则层：谁的楼层、几点后算打扰——首验日"陈默再次进入宿舍"的漏洞
  在这里修）、教学楼、夜市、河堤。
- **地点规则层**：每个地点可有 rules（开放时段、噪音边界、私人区域），
  违规由在场权威 NPC 或引擎判定。
- **节奏纹理**：饭点人流、课程表、周末集市、天气驱动人流（下雨→咖啡馆满）。
- **信息载体**：公告栏（通知=信息源）、宿舍楼群消息、咖啡馆催稿单。
- **氛围人口**：感知里可有"食堂排着七八个人"的环境叙述（不生成 actor）；
  只有 MC 主动搭话才即时生成匿名路人。

## 7. 成本模型

3 MC ≈ 435 回合/日不变；7 NPC × 3~8 次唤醒/日 ≈ +40~80 回合（+10~20%）；
匿名路人按需 ≈ +5~15 次。世界活人感翻倍，成本近持平。
