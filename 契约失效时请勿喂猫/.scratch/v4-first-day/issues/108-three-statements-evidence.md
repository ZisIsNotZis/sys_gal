## 1. 现象

旧判据只数 `speech`/`message` 正文里出现"情况说明"四个字的角色（候选四人：
陈默、林瑶、林瑶室友、班长）。它对一次真实交付两次判错：

- **假阴性**：把说明写成文稿留在辅导员办公室、把稿子 `give` 给辅导员、
  在收件文书上签字——世界里有事件、有物件、有人经手，却一分不算。
  工件 `runs/real-20261018T085705+0800-2116654-169068128.json` 上
  `--day 1` 的读数："提交说明的角色：班长、林瑶"，FAIL。而这一天陈默
  11:18 把《学生会审计包核对说明》`item_given` 交到辅导员手上（id 925）、
  班长 16:13 把《个人情况说明》留在辅导员办公室（id 2201），两件都不在
  计数里。
- **假阳性**：只在对话里说了这四个字就算交过（103 §D1-E2/E3 的"光说不交"）。

根因不在引擎也不在种子（107 §5.2 已登记为判据侧问题）：判据把"说过"当成
"交过"。里程碑要求的是"提交"，它的证据应当是物件落在收件处或交到收件人
手上。

## 2. 新的判定

仍是"三份、来自三名不同角色"（所以不是放宽门槛，是换证据），三类交付物
任一即可、按角色去重：

| 类 | 证据 | 判据 |
| --- | --- | --- |
| a 文稿 | `note_left`（`leave_note` 产生） | 角色在候选四人内，正文命中"个人情况说明／情况说明／书面说明"（裸"说明"与《XX核对说明》不算），`location` = 收件地点辅导员办公室，且 `note_left` 时间 ≥ 16:45 |
| a 交付 | `item_given` | 同一份稿（`item` = 该 `note_left` 的 `note` 编号）由**作者本人**交给 `to` = 辅导员，且 `item_given` 时间 ≥ 16:45；稿写在哪里不影响这一类 |
| b 签字 | `document_annotated` | 角色在候选四人内，`document` 命中收件文书名（个人情况说明／收件表／收件登记／收件簿／说明登记），且时间 ≥ 16:45。签到本、面核记录不算 |
| c 发言 | `speech`／`message` | 降为**辅助**：只进证据行、只在同角色已有 a 或 b 时标注，本身不计数 |

16:45 是 manifest `statement_request`（程序发布）的时刻：它贴出《个人情况
说明程序》、定义了要交的是什么，发布前的稿不是它要求的交付。

不足三人时证据行点名缺谁、以哪种证据缺（含发布前有过、不计入的部分）：

```text
只有 1 人（还差 2 人，16:45 程序发布后的交付物）：班长（文稿 17:33 留在辅导员办公室《个人情况说明》＋发言）；未交：陈默（无任何交付物）、林瑶（16:45 前有文稿 13:46 留在辅导员办公室《书面说明》；交付 13:48 交给辅导员，不计入）、林瑶室友（无任何交付物）
```

足三人时同样点名还差谁，便于运行后分析：

```text
3 份/4 个候选角色（16:45 程序发布后的交付物）：陈默（文稿 16:50 留在辅导员办公室《个人情况说明》）、林瑶（交付 17:02 交给辅导员）、班长（签字 17:10 在《个人情况说明程序》签字/批注）；未交：林瑶室友（无任何交付物）
```

候选角色沿用 ticket 107 的"门禁候选四人"（经手过审计材料的人）：
陈默、林瑶、林瑶室友、班长。收件人（辅导员）不是候选，因此她自己写的
《收件登记》不会被误当成一份提交。

## 4. `--day` 与 `--half` 同口径

两条路径都调用 `MILESTONES[1]` 里的同一个函数（`main()` 只是先按半天过滤
事件），所以判据不会分叉。差别只在事件窗口，这是 `--half` 的定义：

- `real-20261018T085705` 上 `--day 1` → 1 人 FAIL（两处收紧后）；
- 同一工件 `--half d1-pm` → 同样 1 人 FAIL：唯一成立的那份（班长 17:33）
  本就在下午，而时点门槛已把上午的交件赶掉，两个视图的差别因此不再显形。
  半天窗口的差异依旧存在（上午留在收件处的稿在下午视图里没有事件），
  用夹具 `test_green_fixture_passes_in_the_day_and_pm_views` 守住。

半天检查点只能说"这一半里交到了几份"，不是对全天的否认；日末以路线网
判定为准。

注意分类：`d1-三份个人说明` 在 `ROUTES[1]` 里是路线[短信升级辅导员]的
`requires`，不是 `anchors` 成员。因此它阻断的方式是"这条路线不成立"，
`--day` 与 `--half` 都按同一张路线网裁决；把它升级成无条件锚点属于产品
设计决定（会让 D1 只剩一条路可走），本票不改。

## 7. 残留风险

1. ~~裸“说明”兜底仍可能误纳一份恰好留在辅导员办公室、正文偶然出现
   “说明”二字的便条~~ — **已关闭**（第三轮收紧）：裸“说明”与“核对说明”
   一并不再算证据，只认个人情况说明／情况说明／书面说明三个名称。关闭的
   理由：真实工件里它把《学生会审计包核对说明》这类核对记录当成了说明
   材料，位置约束拦不住这种误纳。
2. ~~不校验交付时点：陈默 11:18 那份在 16:45 程序通知之前也计入~~ —
   **已关闭**（第三轮收紧）：三类证据一律只收 16:45 `statement_request`
   程序发布之后的交付物。关闭的理由：程序定义了要交的是什么，发布前的
   稿不是它要求的交付。
3. 候选角色名单硬编码四人（ticket 107）。新人成为经手人时要同改常量，
   否则他交的稿不会被计入。
4. `--half` 只看本半天事件：上午写、下午交的稿，在下午视图里缺正文，
   于是那一份会从半天读数里消失（全天读数不受影响）。
5. b 类（签字）在真实工件里还没有实例，只在夹具中验证过；第一次真实
   签字出现时应复核收件文书名是否命中。
6. 新回归模块放在 `scripts/`（与票据 105 同例），不在
   `harness/tests` 的 pre-run gate 命令里，需要显式跑
   `discover -s scripts`。
7. 收件地点只认辅导员办公室。世界还有一条合法路线：十二点到一点半班长
   在学生会办公室登记收件（见 manifest 的 `[交件, 收件, 交给谁]` 知识行），
   在学生会办公室留下稿子不会被计入。出现“只在班长那个窗口交件”的工件时，
   把收件地点扩成“辅导员办公室任意时段 + 学生会办公室 12:00–13:30”即可。
8. 时点门槛会把“程序发布前就写好并交出”的情形算作未交（真实工件里林瑶
   16:43 交件只差两分钟）。这是有意的口径：程序定义了交付时点；若要承认
   “闻风先交”，需要另立一条判据，不能在证据类型上偷加。
9. 时点比较取 `time[11:19]` 与 `D1_STATEMENT_PUBLISH`（`16:45:00`）直接比
   字符串：要求时间戳带秒（引擎与全部历史工件都是 `…T16:45:00+08:00`），
   不带秒的时间戳会比出版小、按发布前处理（fail-closed，交付物因此不计）。
   跨日与时区目前不涉。“发布前写、发布后仅签字”这类混合情形按各自事件
   时间分别判，证据行逐类列时间。

### 2026-10-18 第四轮：写作时间门槛（Status 仍 fixed）

**问题（ticket 109 §D1-2-E8，真实假阳性）**：`real-20261018T100115` 上
`d1-三份个人说明` 读到 1 人 FAIL，唯一计入的是**林瑶 19:41 重交 12:38 写的
旧稿**——`note-林瑶-12` 是 12:38 写的《绿荫校园社无障碍改造项目情况说明》，
12:40 给过班长、19:31 班长退还、19:41 再交给辅导员；辅导员 19:46 自己登记
为“仅作项目参考材料，不替代今晚的审计经手个人说明”。第三轮的两处门槛
（名称、事件时点）都拦不住它：名称合格，`item_given` 也确实在 16:45 之后。

**根因**：判定只看**交出时间**，不看**写作时间**。程序发布定义的是“按程序
写一份说明交上来”，12:38 写的旧稿再交一遍不是这份交付。

**新的判定**（`_d1_statement_deliveries`／新增 `_d1_statement_redeliveries`）：

| 类 | 条件（全部同时满足） |
| --- | --- |
| 文稿 | 角色在候选四人内；正文命中 `个人情况说明／情况说明／书面说明`；落在辅导员办公室；**`note_left` 自身的时间 ≥ 16:45**（写作时间；文稿类的时点即写作时点） |
| 交付 | 同一份稿由作者交给辅导员；`item_given` 时间 ≥ 16:45；**该稿的 `note_left` 时间也 ≥ 16:45** |
| 签字 | 角色 + 收件文书名 + `document_annotated` 时间 ≥ 16:45（**不变**） |
| 发言 | 仍只做辅助、不单独计数（**不变**） |

「写好于 16:45 前、只在 16:45 后交出」＝**旧稿重交，不计**，并入证据行的
未交说明，且不会被误说成“16:45 前有过交付”：它单独一类，文案为
