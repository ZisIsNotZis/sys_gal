### 1.1 「单实例 vs 库存」这一条线（本轮的主线判断）

世界的物品状态是 `item_locations: {id → 地点}`，**一个 id 就是一样东西**：`leave_note on=<纸>` 且带 persist 时，那张纸被写成一份带编号的文稿并**从世界里销账**（`kernel._complete`：`a.inventory.discard(sheet)` + `item_locations.pop(sheet)`）。于是"一沓纸"这种量词，在世界里只能有两种落法：

1. **多个 id**（同描写、不同名），每件是一件"可以抽走一张的纸/沓"；
2. **补货**——但补货必须用**另一个 id**：票 101 的 E105 门禁钉着"被写掉的那张纸不能又变回空白纸"，本轮第一次实现时用 `add_item 空白纸` 在 12:00/18:00 补同 id，`test_a_written_sheet_is_a_note_that_can_be_handed_over_and_read` 与 `test_replay_rebuilds_the_handed_over_note_and_the_used_sheet` 立刻变红（那张被写满的纸"复活"了）。改成 `草稿纸`（12:00）/`说明用纸`（18:00）两个新 id 后两处全绿。这就是为什么最后是"六件同类物 + 两次异 id 补货"，而不是"两个 id + 补货"。

## 2. 三处设计与理由

### 2.1 为什么不给 `老家属院` 开一条真路由

父票给的第一个选项是"给老家属院一条真实路由（例如 中庭→校门→老家属院）"。本轮**没有**采用，理由是它同时推翻两条既有世界事实：`红色哨子`/`蓝色兔子雨伞` 落在地下室、当日拿不到（`completeness: missing/belief`，票 84 的裁定），以及 `laozhou_night_shelter` 里"回老家属院的末班大巴今天已经开走"——一旦校内能走到，这两条都要重写，`test_unreachable_names_get_a_story_executable_alternative`（要求 `move 老家属院` 仍被拒）也会转红。采用的第二个选项：**给一处她真走得到的打听现场**。

`家属院门口` 因此被登记成"临街的那一段"（院门、门内楼道口、院门口铺子），只与 `陈默家` 相连，**同样标 `remote: true`**：校内的人当日过不去（`陈默` 实测仍被拒），地下室的哨子与大爷的末班大巴都不变；而"她下楼两分钟就能到场问人"第一次成立。她的角色页"只通过电话和消息出现，永远不会出现在校园"仍然成立——院门口不是校园。

### 2.2 为什么不给催办加广播，而是加两条只投给陈默的提醒

16:00 那条门缝纸是**地点作用域**（当时学生会办公室无人 → `visible_to=[]`），那是正确的世界事实，不该改。16:05 的捎话也**确实**送到了他眼前（16:04 感知里就有），问题是他那一回合被"让林瑶核验原件"吸住、之后再没回来。把这件义务再播一遍给所有人会重开票 96 关掉的泄漏门（当时正是"广播把催办单正文念给 12 个人"）；所以改成两条**只投给当日值班**的重复提醒，各自附一条可达的动作（去学生会办公室读那张纸）。命令只有一条：`visible_to=['陈默']`（§4-3 实测）。

### 2.3 收件档的纸为什么放在辅导员办公室

`_d1_statement_deliveries` 认的是"当场交给辅导员"；而 19:00–21:00 的收件点在辅导员办公室，学生会办公室到这里要 780–840 秒。D1-2 里三个候选人在这个窗口里全部没有交件，理由是"没有独立空白纸"——那时纸在 840 秒以外且已经没了。收件桌上放一沓 `说明用纸`（18:00，定向点名辅导员），只是把"写字的地方"和"交件的地方"放到同一间屋里；写不写、交不交仍由角色定。

## 5. 仍缺（5 条）

1. **求助点/权威渠道（E4）没有注册**。白天"部门名录问谁"、夜里"大爷能在哪待一晚"仍共用同一个缺口。要做需要一条产品层裁定：注册 值班室/保卫处 值班点（可达、有人守、有一条"访客登记"的明文流程），并同时给 extra 一条可答的最小事实（E7）。本票按"不新增世设"处理，没有动。
2. **纸张仍是"一个 id = 一样东西"**：19:00–21:00 收件桌上最多三份同时可写，第四人只能写不带 `on` 的 persist 文稿（世界允许，知识行也写明了"纸笔不是前提"）。补货只到 18:00，18:00 之后用完就没了。
3. **`便签本` 的"撕一页"仍没有模型动作**（E10）：它带正文、走 `document_annotated`，与"撕一张纸"是两条路。本票把程序正文里"随手撕一张就能写"的措辞改掉，没有给它加物品行——加了就等于在同一处再登记一次纸，属重复登记。
4. **20:20 只是"可执行"，不是"会发生"**：D1-2 里她选择 `wait sleep:true`；本轮没有加任何强制唤醒或必做动作（那会把她的自主性拿走）。同理，17:00/18:50 两条提醒只是"送到眼前"，接不接住仍是模型的事，`_d1_audit_relayed` 的字面要求（16:00 后说"催办单"）本轮没有放宽。
5. **世界前言的【走路】段会列出 `陈默家 ↔ 家属院门口：步行约 2 分钟`**：`world_primer` 不过滤 `primer: false` 的路由（既有的 `夜市 ↔ 后街糕点铺` 同族）。它不授予任何走法（校内到不了这两个点），但每个角色都会看到这一行；要真正屏蔽得改 `harness/world_loader.py`，不在本轮范围。
