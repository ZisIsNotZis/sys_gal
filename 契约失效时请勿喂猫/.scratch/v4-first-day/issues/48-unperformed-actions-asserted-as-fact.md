# 48 — 没做的动作、没读的内容被叙述成已核实事实，并扩散成他人的记忆

Status: ready-for-agent
Need-review: yes
Need-test-cases: yes

## 复现与证据（同一工件，四名独立复盘者各自报出）

同一个故障形状反复出现：**工具从未成功 → 角色照旧叙述成已完成/已核实 → 世界接受并扩散。**

| 角色 | 回合 | 叙述 | 事实 |
|---|---|---|---|
| 宿管阿姨 | i=254/263（11:51/12:17） | "没见着'林瑶'俩字""晚归本上没有她的名字" | 5 次 `read 晚归登记本` 全被拒，全run她 0 条 `document_read` |
| 林瑶（主角） | i=217→229（11:09–11:24） | "柜开了，抄件在我眼前：三通、23:30、目击那行在" | `read 蓝皮夹抄件`/`take` 双双被拒；细节逐字来自 extra 陈大爷的口述 |
| 陈默妈 | i=188/193（10:38/10:40） | "妈这边拨那号码也不通，空号音" | 世界里没有拨号动词，她也从未拨过号；陈默随即记下"我和妈都拨过" |
| extra 韩大叔/陈大爷 | 12:42 / 10:36–10:56 | "好，开柜了""柜开了…你接稳了""我读过该页无数遍" | 无任何 open/take/give 事件；extra 的 affordances 全为 `[]` |

后果不是一句话说错：**宿管阿姨的伪造内容进了林瑶室友的记忆**（她 12:24 记下"瑶姐昨晚压根
没登记"）；**extra 的伪造抄件进了主角的行动计划**；**陈默妈的假电话成了"共同核实"**。
世界缺少一道"你并没有做过这件事"的约束。

## 根因

1. 没有"动作动词"的地方（拨号、签字、批注、当面核验）既没有工具，也没有明确的**不可用**
   反馈，模型于是用叙述补上；而 T1"文本即说话"契约把整段文本当台词送出，世界照单全收。
2. 世界对"断言"不做校验：`speak` 文本里的既成事实不与事件日志比对，也没有"该物件不存在/
   该动作不可用"的提示路径。
3. 读取被拒时的错误信息（issue 39）把"没有正文"说成"不在你手边"，进一步鼓励角色相信自己
   "其实看过了"。

## 验收方向

1. **动词缺口显式化**：角色想做的常见事（拨打电话、签字/批注、当面核验、开柜取件）要么
   给真实动作并产生世界事件，要么给出明确的"这个世界没有该动作"反馈——不要留白。
2. **断言-事实校验（最小可行）**：对"带既成事实口吻 + 指向未建模实体/未发生事件"的
   `speak`，至少给出系统侧提示（"你没有做过这件事/该物件不存在于世界"），并让检查器能统计
   发生次数。不求全自然语言理解，先做"具名实体未注册"与"同一物件被断言已读但无 document_read"
   两类。
3. **可核查性**：把"声称读过某文档但无对应 document_read"做成检查器指标（现run这一项会亮红灯）。
4. 回归（先红后绿）：夹具 A——角色未读某文档却说"我核过了" → 断言产生系统提示/计数；
   夹具 B——extra 叙述"开柜了" → 断言被拒或改写为意图；夹具 C——宣称拨号 → 断言反馈"无此动作"。
