## 4. 仍缺项（5 条）

1. **台账事实表仍不可猜（票 94 §1 / 报告 R1，P0，seed 侧未动）**：引擎已把 `facts` 的 `keywords` 能力落地（`harness/system.py` 支持 `问句: {answer:…, keywords: […]}`），本票**没有**改种子那三条——它不在本轮的必改清单里，改它等于擅自决定「红色哨子那条要不要留」。下一轮就三行即可：给「2013年邻里撤离通知书责任人」「当前记录的期限」各配 keywords，并处置与本案无关的「红色哨子」条目（接线索或移出）。窗口 4 的证据是 5 问 0 答、0 条世界痕迹。
2. **三条 16:xx 事件现在可能一个人都不通知**：`location:` 已生效（引擎侧票 95/E97），实测 `visible_to=0`（当时无人在学生会办公室）。这正是指令要的「谁在场谁知道」，但代价写在明处：`audit_deadline`/`statement_request` 的传播完全依赖「有人恰好到场读到那张纸」或别人的二手转述；`audit_pack_review` 对 `E72b`（「审计实质的 pm 场合任何旁观者都听得见」）只剩「到场的人听得见」——**用例仍绿（它只判 `target` 是否为空），意图实际收窄了**，请评审确认这一条是否接受；若不接受，替代写法是保留这行广播、只把正文换成现场事实（泄漏照样被堵住）。
3. **「到教室」现在只解决「走到」，没解决「课上发生什么」**：302/305 是空教室，没有任何「上课 / 下课 / 点名」的排程或在场角色；`morning_class_bell`（08:00）、`afternoon_class`（14:00）只是校园广播，不点地点。林瑶室友今天到得了 305，但到了也只是站在一间没人的教室里。要真演「上课」需要教室级的排程（谁在里面、上到哪一节）与能演讲课的在场者——属下一轮的故事层设计，不在本票。
4. **`老板娘` 这个词在种子里仍指四个不同的女人**（小卖部 role_prose、后街糕点铺 extra alias、半坡咖啡馆老板娘、`唐小岚` 自己的 role_prose 里也有一个）。本票只让「去铺子带话」这一条有确定指向；其余三处仍是歧义源，`dead_aliases` 之外没有机械检查能发现。收窄它们会动到别的窗口的派工语言，留给下一轮统一。
5. **`便签本` 变成可读之后，它的正文是一条新世界事实**（三楼走廊有一盏灯坏了、课表今天补了一张）。没有排程维护它，也不随 D2–D12 更新；若后续窗口继续读这本，会读到一张停在 3/16 的纸——与票 92「课表只有 3/16 一天份」同族，需要同一套「按天投放」的处理。

#### 4. 本轮发现的引擎侧缺陷（P0，**已移交引擎所有者（票 95）**，本票未改 `harness/`）

**症状**：种子按 `docs/V4-AGENT-INTERFACE.md` §5 的写法补上 `keywords` 之后，在**真种子路径**上 `keywords` 完全不生效，而且台账的 `answer` 会变成一段 Python dict 字面量投给陈默。引擎自己的 `LedgerFactMatchingGates` 全部绿，因为它们把 dict 直接交给 `Ledger`，绕过了 `load_world_pack`。

**证据（`v4/` 下实测）**：

```text
load_world_pack("world").system["facts"]["红色哨子在哪里？"]
  → "{'answer': '老家属院的地下室', 'keywords': ['哨子', '红色哨子', '红哨套', '哨套', '老家属院', '地下室']}"   # str，不是 dict
Ledger(pack.system["facts"], pack.system).fact_keywords
  → {'红色哨子在哪里？': (), '2013年邻里撤离通知书的责任人是谁？': (), '学生会审计核对的期限是什么？': ()}
Ledger.query(world, "陈默", "红色哨子在哪里？").payload["answer"]
  → 上面那串 dict 字面量（visible_to={'陈默'}）
```

**根因**：`harness/world_loader.py:228-230` 的历史代码 `manifest["system"]["facts"][key] = strip_refs(value)`——值原来是纯字符串，`strip_refs` 对它无害；票 95 允许值是 mapping 之后这行没有分支，`strip_refs` 对 dict 做了 `str()`。同一文件 749-772 行新加的形状校验认 mapping，但这条 strip 循环紧接着把它毁掉了，所以「校验通过、运行时是字符串」。

**最小修法（已交给引擎所有者，本票不落）**：

```python
for key, value in (manifest.get("system", {}).get("facts", {}) or {}).items():
    if isinstance(value, dict):
        manifest["system"]["facts"][key] = {
            "answer": strip_refs(value.get("answer", "")),
            "keywords": [strip_refs(k) for k in (value.get("keywords") or [])],
        }
    else:
        manifest["system"]["facts"][key] = strip_refs(value)
```

（`strip_refs(key)` 那条重复写入可去掉：key 无 `[[ ]]` 时是自赋值。）
