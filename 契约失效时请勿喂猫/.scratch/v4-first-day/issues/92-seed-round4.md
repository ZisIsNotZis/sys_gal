## 4. 仍缺项（5 条）

1. **教室仍不可进入**：本轮按任务给的第二个选项执行——房号写进课表正文、边界写进正文与 `unreachable_targets`，不注册新地点。若某个窗口真要让角色进教室上课（而不是走到教学楼），那需要「教室地点 + 双向路由 + 楼里可办的事」三件套，且要防它在没有课的时候变成一间空房。
2. **泡茶 / 端热饮没有对应动作与物件**（提示+引擎层，移交）：动作面只有 take/give 等，咖啡馆也没有「一杯热茶」这样的物件，所以「给客人泡一杯」在引擎里无法完成。种子这一轮做的是「把今天出不了热饮写成可查的事实」，让角色一次说清；真正的服务能力要引擎补动作或补物件。
3. **extras 会自行点热饮**（提示层，移交）：韩师傅 08:06「我喝杯热茶就行」、孙师傅 08:47「我来杯热茶就行」——两位陌生人各点了一次店里做不到的东西，这属于 `npc_agent` 的取物/点单边界，不在种子。票 90 未单列，建议下一轮引擎票收。
4. **学生会办公室的收件人只在 3/16 中午被补上**：`值班簿` 是静态文书，D2–D12 的同一时段又没有人坐班，「交上去有人看」这个缺口会在第二天复发（要么按天补、要么由引擎的常驻安排承担）。
5. **课表只有 3/16 一天份**：那张纸压在值班台上不会换，D2 之后有人问“今天的课”读到的是旧表。多日弧线里目前没人问课（课表线集中在 D1 上午），但要在 D2+ 复用这条线，需要每天投一份，或把课表做成“当天有效”的投放物。
