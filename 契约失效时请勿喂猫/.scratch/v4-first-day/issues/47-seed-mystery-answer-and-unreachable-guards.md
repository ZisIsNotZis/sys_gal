# 47 — 种子：谜底随知识注入泄露、克制守则检索不到、角色招牌道具与记忆物件未落地

Status: fixed
Need-review: yes
Need-test-cases: yes

## 复现与证据（同一工件）

1. **谜底提前泄漏**：辅导员首屏 `# knowledge` 就带
   「[学生会审计]: …两个总额没标用途，手写更正没署名，底层凭证不在包里」
   （`manifest.yml:1437-1442` 的 `audit-case` desc 含答案，且 `known_to` 含辅导员），
   她 i=238 未经任何读取就把它写进记忆；她在 T6 说"亲眼看看包里是什么"因此变成走过场。
   → 谜题类条目的 desc 应是**谜面**，不是答案。
2. **克制守则送不到**：陈默妈的种子里有"具体姓名我记不清了——不该猜的就不猜"，但该行
   key 是「老街坊代表」，剧情词是「街坊代表/2013年台风」；`kb.hits` 只比 keys、双向子串均
   不命中，于是**守则从未出现在她眼前**，她当场编出"张建国＋1395731xxxx（他儿子）"，
   并扩散给陈默（陈默随后写下"我和妈都拨过"）。**抑制性知识必须按剧情词汇可检索**，
   否则等于没写。
3. **招牌道具没落地**：班长人设"我手里永远有几张表"，但 `考勤表/二班考勤表` 在整个 v4 世界
   零命中；他 i=230/256/268 三次取/交失败，当着辅导员的面露怯。同族：唐小岚记忆写着
   "编辑把[[催稿单]]贴在吧台上好几天了"，而催稿单只是 `kind: generic`、场景里从不可见。
   → 角色卡/记忆里点名的物件必须注册并可操作，或改写记忆。
4. **同名撞车**：失踪学生「小陈」与下棋大爷口中的陈默（也叫"小陈"）同称，林瑶 12:42 当场
   搅混，大爷 12:51 需专门澄清（世界事件 #1273/#1277/#1320）。这次产出了好戏，但属于
   高风险命名，宜在种子里避免或明确区分（如"小陈（学生）/小陈（陈默）"）。

## 根因

种子的**知识条目**承担了三种不同职能——谜面、答案、行为守则——但没有区分；`kb.hits` 的
检索只看 keys 字面；`completeness/known_to` 只约束物件存在性，不约束"这条知识该不该现在
给到这个人"。

## 验收方向

1. **知识条目分级**：谜题条目只放谜面（答案另存并在读取/事件后解锁）；守则/抑制类条目
   必须绑定到可检索的剧情词汇（或豁免于 keys 精确匹配，按双向子串/概念名命中也返回）。
2. **lint 扩展**：角色卡/记忆里出现的具名道具必须注册为可操作实体（有 location 或明确
   `missing/belief`），否则红——这条把 issue 35 的契约从"排程通知"扩展到"角色知识"。
3. **回归（先红后绿）**：把答案写进谜题 desc → lint 红（或断言该行不进首屏）；
   守则行 key 与剧情词不一致 → 断言角色仍能检索到；角色卡提到未注册道具 → lint 红。
4. 命名风险：种子引入近似/重复称呼时，lint 给出碰撞提示。

## 追加（2026-09-30，lane 2a 交付后自查发现）
`items:`/`documents:` 行的**内联 `content` 文本没有被名字 lint 覆盖**：`seed_lint.py` 只扫
`characters/*.md`、`items/*.md`、`documents/*.md` 等正文文件里的 `[[标记]]`，manifest 里新加的
`content` 字符串是"法外之地"（本次四个登记本用了 `小满`/`纪风`，恰好在别名表里，属于运气好）。
本 lane 需扩展：内联 content 里的具名实体同样必须解析到注册实体/概念（或要求用 `[[标记]]`），
否则新写的正文可以悄悄引入模型与 `flashback` 都认不出的名字。
