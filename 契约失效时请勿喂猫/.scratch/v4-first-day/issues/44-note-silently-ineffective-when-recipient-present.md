# 44 — 字条：作者与收件人同处一室时静默失效

Status: fixed
Need-review: yes
Need-test-cases: yes

## 复现与证据

- turn 163（09:51，校史档案室，`nearby_actors=['陈默']`）：林瑶 `leave_note`，内容是给
  陈默的**借条**（"借出：2013年台风台账一份、移交存根一件……经手人：陈默（值班）"）。
  工具结果只有 `"submitted"`，没有任何受众说明。
- 世界事件 #645 `note_left`（09:53，visible_to=[林瑶, 陈默]）之后——**全run再无任何 note
  相关事件**（`{e.kind for e in world_events if 'note' in e.kind} == {'note_left'}`），
  即这张字条**从未被任何人读到**。
  更正（2026-09-30 核查）：`note_read` 机制**本来就存在**（`kernel._consume_notes`，在 enter 时
  投给第一位非作者进入者并焚毁，事件 kind 已是 `note_read`）。所以本条的缺陷不是"缺机制"，而是
  **反馈与可判性**：那条字条之所以永不被读，是因为作者与唯一的目标读者当时同处一室、且此后没有
  任何非作者进入该房间——机制没触发，而作者对此一无所知（回执只有 `submitted`），也拿不到
  "我的意图没送达"的任何信号。
- 原因链清楚：字条机制按用户裁决是"第一位非作者进入者私下读到全文并阅后即焚"，而在场者
  不算读者；陈默当时就在屋里，10:41 离开后再未返回该房间（世界事件 #757 之后行程为
  中庭→教学楼→辅导员办公室→食堂），此后档案室只余作者林瑶。
  → **作者想给"站在眼前的人"留条，语义上不可能成功，但工具照收，作者一无所知。**
  林瑶写白条的剧情意图（借阅留痕、请值班人补签）就此消失。

## 根因

`leave_note` 的语义（未来首个非作者进入者、阅后即焚、在场者不读）只写在工具描述里，
**结果回执不回述**；且当在场者很可能就是收件人时不提示改用 `give`。世界"接受"了一个
注定无人读的动作，作者得到假成功。

## 验收方向

1. **回执必须说清受众**：`leave_note` 成功后回执要写明"在场者不会读到；只有之后第一个
   进入该房间的非作者会读到全文并焚毁"。
2. **现场提示**：当 `nearby_actors` 非空时，回执（或调用前的选项）要指出在场者名单，
   并给出 `give`（当面交付）作为可达手段。别让作者用留条去满足当面的意图。
3. **可判性**：`note_read` 事件已存在（含读者、作者、left_at、正文），这条**不需要新增事件**；
   需要的是让"未送达"也可判——例如字条在场景结束仍挂起时留一个可观测迹象（或在运行结束时报告
   未读字条数），否则工具缺陷类问题只能靠人肉读轨迹发现。
4. 回归（先红后绿）：作者在场者非空的夹具 → 断言回执含受众说明与 `give` 提示；断言
   字条被首个非作者进入者读取时产生 note_read/焚毁事件，且内容不进入在场者感知。
