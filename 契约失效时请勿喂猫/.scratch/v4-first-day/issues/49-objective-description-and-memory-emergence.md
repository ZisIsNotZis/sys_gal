# 49 — 客观描述与记忆涌现：看见即得描述，"读"不再是手工杂务

Status: fixed
Need-review: yes
Need-test-cases: yes

## 用户设计的机制（2026-09-30，裁定）

1. **每个实体都有客观描述**：人物、物品、地点各自带一份 `objective` 描述——就是"当人真的看到
   或到达时应当自然涌现的那段客观陈述"，不含任何主观事实、不含他人的想法、不含剧情答案。
2. **看见即写入记忆**：角色一旦看到某实体（物品进入视野、人物同处一室、抵达地点），引擎**立即**
   把该实体的客观描述作为**新增记忆**写进这个角色的记忆系统；主观解读仍归角色的主观记事本。
   之前记忆里没有它是对的；看见之后就应当有。
3. **兜底取用**：如果模型问起一样它"确实看见但记忆里没有"的东西，系统层直接从实体注册表取
   客观描述给它，而不是让它猜、更不是回一句"不在你手边"。
4. **阅读不再由模型手工触发**：物品/文档进入视野后，停留满 `reading_seconds` 即视为读过；
   "这几回合内没有读过，它就已经被读了"。仍产生 `document_read` 事件，使里程碑的证据链
   （亲读互证）成立——依据从"点过按钮"变成"人在场且停留足够"，这依然是客观可验的事实。

## 要修掉的现症

- issue 39（24/72 错误回合）：items 有正文却不可读、报错说谎、建议不可执行。本机制落地后
  "看得见却用不了"这一整类消失。
- issue 48（一半）：读不出来 → 角色替它编内容 → 编出来的内容进入他人记忆。客观描述作为
  唯一权威来源后，编造有了明确的反面依据。

## 验收方向

1. 实体注册支持 `objective`（缺省可由 title/desc 派生，但剧情关键实体必须手写）。
2. 看见/到达 → 生成可观测量（世界事件 + 该角色记忆行），且**客观描述不含剧情答案**：
   lint 断言 `objective` 里不得出现 `completeness: belief/missing` 所保护的答案内容。
3. 停留计时：进入视野时开始计时，达到 `reading_seconds` 即发 `document_read`；提前离开则不算。
4. 兜底取用路径有测试：记忆缺失但实体在视野内 → 返回客观描述，且不产生主观措辞。
5. 回归（先红后绿）：把 `签到本`/`晚归登记本` 放进视野 → 断言角色记忆里出现客观描述、
   且不再出现"读不出"的拒绝；断言 `document_read` 在停留满时长后产生、提前离开不产生。
6. 里程碑检查器随证据链语义更新（"亲读"= 在场且停留足够），并在文档里同步说明。

## 遗留（lane 2b 去重收尾时发现，当前 0/36 命中，属潜在而非现行）
去重的逐字比较两侧来源在**截断规则上不一致**：`world_loader._plain_description`（KB 行）在
第一个空行处截断，而 `prompt._clean_description`（`[所见]` 行）保留全部段落。因此若将来某个
实体的 mkdir 正文含"空行 + 第二段"，KB 行会是 `[所见]` 行的严格前缀，逐字比较失败 → 两行都留
（部分重叠）。当前种子里 36 个实体描述无一出现该差异，故今天不会重复。
待办：把两侧的取文规则统一到同一个函数（或让 KB 行不截断），并加一条"含空行第二段"的回归测试。
