# Issue tracker（本实验）

本实验的 issue / 工作记录都在此目录。计划（里程碑与工作包）在
`../ROADMAP.md`；当前进度在 `active-work.md`。本文件是**追踪器索引与
状态对账**，随追踪器结构变化而更新。

## 约定

- 一个 feature 一个目录：`.scratch/<feature-slug>/`
- 规格：`.scratch/<feature-slug>/spec.md`
- 票据：`.scratch/<feature-slug>/issues/<NN>-<slug>.md`（从 01 编号）
- 状态行：票据顶部 `Status:`；对话与证据追加在 `## Comments` 下
- 票据是**过程记录**（append），不是事实文档；当前事实在项目文档里

## 状态词汇

| Status | 含义 |
| --- | --- |
| `needs-triage` | 维护者待评估 |
| `needs-info` | 等待补充信息 |
| `ready-for-agent` | 已充分规格化，可交 agent |
| `ready-for-human` | 需要人类实现/裁决 |
| `claimed` | 已认领、进行中 |
| `fixed` | 修复已提交、套件全绿；独立验收未记录（历史票多用此态） |
| `done` | 完成且（如需要）已记录验收 |
| `deferred` | 明确延后 |
| `wontfix` | 不做 |

历史上大量票据在修复提交后未回填状态行；2026-10-13 已按 `fixed` 对账（见下）。
