# Provide a reachable archive opening path

Status: wontfix
Type: enhancement

The closed harbor archive has no reliable available custodian or opening route, so a character can discover the location yet reach a world dead end. The correct setup depends on whether its access procedure is ordinary public knowledge or a concealed fact: generic physical and social common sense belongs in the agent/system contract, while the archive's specific status, access route, secrecy, and known custodians belong in scoped world/character seed data.

## Agent Brief

**Category:** enhancement
**Summary:** Make location access and knowledge classification explicit without embedding plot logic in the harness.

**Current behavior:**
The harbor archive can be closed and reachable, but the engine lacks a durable abstraction for ordinary access conditions, discoverable procedures, and scoped knowledge about those conditions. This risks either a dead-end world or accidental disclosure of seed secrets.

**Desired behavior:**
The harness loads objective access facts from world data and exposes only facts legal for the observing character. Generic common sense belongs to the engine/system contract; public archive facts are observable world data; secrets remain private until a character earns or receives them through a legal event. The harness never opens a location merely because an investigation or plot would benefit from access.

**Acceptance criteria:**

- [ ] The world pack can represent a closed location boundary and valid access conditions without plot-specific engine code.
- [ ] Public access information is available through legal observation, while character-private access knowledge is visible only to its owner.
- [ ] The engine validates access attempts against objective state, schedule, permissions, reachability, and required items or interactions.
- [ ] A failed access attempt changes no unrelated world state and returns an actionable actor-local result.
- [ ] Tests prove that a character cannot learn another character's private access knowledge by observing the location.
- [ ] Tests prove that the engine does not synthesize a custodian, key, opening, or success absent from the world pack.
- [ ] The implementation remains story-neutral: no quest, romance, affection, or forced-resolution logic is added.

**Out of scope:**

- Choosing the harbor archive's final custodian, secret, or narrative role.
- Adding relationship scores or plot phases.
- Modeling every ordinary physical object as a separate world file.

## Decision rule

- Generic common sense: system/engine contract.
- Public facts about this archive: public world seed and legal observation.
- Secrets about this archive: private character seed or earned observation only.
- Whether access is actually possible: objective world seed, with no automatic plot guarantee.
