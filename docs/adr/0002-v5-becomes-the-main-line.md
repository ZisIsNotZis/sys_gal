# ADR 0002 — 主线从 v4 迁到 v5

- 状态：已采纳（取代 ADR 0001 第 3 条）
- 日期：2026-10-20

## 背景

ADR 0001 第 3 条把"活动线"钉在 v4，理由是当时只有 v4 有可跑的引擎。v5 重写了世界模型（十条原始项 + 库 + 种子），并已依次通过：M0 规格冻结、M1 玩具世界与四条反向门、M2 库 v0 与四路径可达、M3 模型试点（`v5/docs/V5-M3-PILOT.md`，87 项测试 + 结构检查 + 反作弊三检全绿）。用户在同一次同步里批准了"v4 在 M2 通过前继续当主线、之后归档为参考"这一条件。

## 决定

1. **v5 是当前主线**：文档、代码、provider 运行都在 `契约失效时请勿喂猫/v5/`。
2. **v4 归档为参考**：不再演进；保留用于溯源运行纪律（打包、检查点、运行后分析）的出处。
3. **v1–v3 历史归档**：不得据以判断当前行为。
4. ADR 0001 的其余各条继续有效（唯一追踪器、SSOT 地图、两种里程碑分层、计划 SSOT）。

## 后果

- 项目 `README.md` 的版本表与 SSOT 地图、`ROADMAP.md` 的抬头、`AGENTS.md` 的预门随之更新，v5 有了自己的预门（`v5/tests` + `v5_lint --strict` + `anti_cheat`）。
- 需要 v4 的机制（轨迹打包、半天检查点、记忆巩固）时，按 `v5/docs/V5-ROADMAP.md` 的里程碑从 v4 搬回，而不是重新发明。
