# ROADMAP — 里程碑、工作包、决定了什么、还开着什么

一个读者要判断这个目录的进度，看这里或从这里跳一次就够。

**主线**：v5（`契约失效时请勿喂猫/v5`），见 `docs/adr/0002-v5-becomes-the-main-line.md`；v4 及更早是参考线，它们的文档不作现行要求。**工作包**：契约、证据与决定进提交信息与本文件；`.scratch/` 只留给跑出来的缺陷。

## 从哪开始

在 `契约失效时请勿喂猫/v5` 下跑门（细节与全套命令在 `docs/9_IMPLEMENTATION.md`）：

```text
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/v5_lint.py --strict
python3 scripts/anti_cheat.py --verbose
python3 scripts/pack_trajectory.py check
```

## 决定了什么（连同它推翻的条件与代价）

- **判据写成观察到的事，不写名字里的想象** — 我改的。`半日一局` 的第三条判据原来只写"续跑因果连续"，而当时唯一的断点是《末班车》二十几分钟的中点："半天"是名字，不是那一局的形状。两件事一起做：把不真的名字换成真的（`half_day_clock` → `mid_run_clock`），把缺的能力补上（过夜之后时钟翻日），再把判据写成两处证据各自在哪。代价：三支故事的脚本轨迹重新生成了一遍，s2 的摘要全动。
- **演员试点的门关在《借条》一支故事上** — 人给的答案，assent: agreed。门覆盖《借条》的模型报告与反作弊三检；《末班车》的模型报告不进这道门，移进下一个里程碑的阶梯，在那里同一套世界、同一套检查在第二支故事上跑。人给的理由：一支故事已经证明机制能让模型自己走出它的路，同一份证明的第二个副本属于下一个里程碑旁边。
- **判据必须有反向控制** — 我定的。一条判据在坏掉时没有东西变红，它就不算存在。已经这么做过的：结局唯一性（把阈值退回常数即红）、空档（拿掉一件排程即红）、盘点（把数写死即红）、整日（拿掉一条路的空动作即红）。
- **数做成的事，不数尝试；同一把尺子不得只量一支故事** — 我自己的。第一次追"同尺度"时《婚礼》加了 27 个动作，其中 13–17 个是失败的，而测试数的是 `kind == "turn"`，把失败也当成功。修法三件：只数 `ok` 的 turn；十二条路的失败动作必须为零（故意要表达的失败得在 `INTENTIONAL_REFUSALS` 里登记并扣掉，现在空表）；空档判据提到两支故事共用的文件，一条断言量八条路。代价与诚实：为不让比值掉出带外，《夜班》也长了 5 个值守动作——内容成立，但那是指标在推内容，写在这里免得下次有人拿"抬分母"盖住真缺口。
- **门绿不等于判据达成：轨迹要读** — 我自己的。两支新世界第一次合入时，《婚礼》的路 a/c 停在 09:2x（"散场时间：还没到散场"），而 `anti_cheat`、lint、187 支测试全绿，因为整日判据只验了路 b。修法：脚本末尾补"世界自己走到下一个排程点"，测试改成四条路逐条断言。预防：一个包回来时先读一份轨迹的头尾，再跑门。
- **派出去的活要在指定的工作树里落地** — 我自己的。有一次提交落在了 `master` 而不是它的 worktree 分支。没丢东西，但此后派包要求接收方先自证 `git rev-parse --show-toplevel` 与 `git status -sb`。
- **反作弊第三检不改：一条路写两遍就是一条路** — 人给的答复，assent: agreed。原话的意思：脚本能用就继续用；脚本跟实际合理性打架时改脚本，别为脚本硬凑不自然的东西；也别为它花太多时间——每支实验自己的判据在它自己的目标上。落成两条：`len(distinct) < len(variants)` 留着；一支故事想殊途同归就写成一条路，不写假差异喂指标。
- **两件便宜的加固，登记但不花时间** — 人说过不为脚本花时间，所以只排队：(1) `R10` 只钉住"退回 2"，改成常数 `3` 它仍绿，补一个 4 条路 / 3 个结局的用例就钉死；(2) `engine/seed.py` 的 `ALLOWED` 只约束 `places`/`people`/`objects` 三段，`schedule.effect` 没有形状约束，多写的 `actor`/`say`/`do` 会被静默吃下——把它也写进 `ALLOWED`，"排程里替角色做决定"就从检测变成加载期报错。
- **并行写者各拿一个工作树，由本层合并** — 据 `Git`（一个区域一个写者）推的。三个包改同一棵 v5 树会读到彼此改了一半的编辑，同一个门跑出来的差别就不来自包本身。
- **物权（谁最后拿着）留在种子层** — root，assent: assumed。P3 的包含关系足以表达押金条与钥匙移交，由 lint 记为"定义在使用处"。会推翻它的是：某支故事需要一种包含表达不了的持有关系。
- **v5 不走票制** — root，assent: agreed。工作包的契约、证据与决定进提交信息与里程碑报告；`.scratch/` 只留给跑出来的缺陷。
- **层与层之间没有"信/票"这套信箱** — 撤销。曾经约定过"消息进 `inbox/`、报告进 `mail/`、状态进 `work/state.md`"，人指出这套东西已经不存在；信息现在只落在 `docs/1…9` 的对应层，永远在这里或从这里的指针下一跳。残留的目录已删除，任何"汇报"都是把事实改进它该在的文件，而不是另写一封。
- **旧的文档家退役，内容只留一份** — 我改的，人的指令是"按规矩迁移"。`docs/PLAN.md` 与 `docs/PRINCIPLE.md` 的内容分别归到 `0_ROADMAP`/`1…5`；`v5/docs/V5-*.md` 归到 `0_ROADMAP`/`4`/`5`/`6`/`7`/`8`；`docs/archive/`（一份 v3 监控的会话交接）与 `docs/reference/`（一份通用的中文网文类型百科，不是本项目的当前事实）整目录退役，历史留在 git 里；`契约失效时请勿喂猫/ROADMAP.md` 留成三行指针，因为 v1–v4 的归档文件还在引用它。代价：旧链接的落点变了，好处是一个事实只有一个家。
- **文档按层分家** — 规则本身在 `AGENTS.md` 与本目录的层级文件里：一个事实只有一个家；文档写当前事实，不写日期叙事、不写 changelog、不写"曾经是 A 后改 B"。

## 还开着什么

- **《婚礼》的"十人同场"只在场、不参与**。十一个人里十个动过手，但酒店经理一人 19–22 件、伴郎 11–12 件，其余多数 1–3 件；"同场十人的记忆互污"只由两个人撑着。要不要为此开一包是判断，不是技术。
- **《夜班》的店长每条路只有一句话**。远程通道成立，压力没演出来。
- **"在登记本上落一行"有两个动词**：`sign` 与 `shift`（落一行 + 交钥匙）。规则同一条，实现两份。留着，因为它实现的是制度上的一个动作；会推翻的条件是第三个世界要"落一行 + 交出一样东西"而那不是交接班。
- **《婚礼》与《夜班》的量是同尺度，但达成靠两段共用的日间内容**：每条路真正分叉的部分一边 11 件、一边 22 件。
- **物权 的第二次声明**：某支故事需要包含表达不了的持有关系时回来。
- **半天这一段是真的，但它是空的**：《夜市》真的从 18:30 走到次日 08:00、轨迹印次日日期；密度留给《快递站》与长弧。
- **T-A 的正文只在参考线里**：长弧以"结局 T-A"引用它，正文定义在 v4 的参考文档，定稿与否留给 S7。
- **《末班车》的第二轮真模型运行**：先把它的处境（包一直在一人手里、没人把它落在座位上）搭进种子，再跑；需要一张新授权。
- **`契约失效时请勿喂猫/.scratch/` 在 HEAD 上是 tracked**：v3 时代的旧缓冲。不是违规，但谁下次碰它就把还有价值的搬走、没价值的带理由退役。
- **期限的中途打断没有接在真实运行路径上** — 核对所有 `submit` 调用点后确认：故事脚本与 `stories/agent_loop.py` 都不传 `effects`，所以真实运行里的动作一口气做完，落在区间里的排程在动作结束后才被 `drain`；"到点关门把动作切断"这条机制只在 `tests/test_m4_deadline.py` 用一张测试替身效果表成立（`docs/8_DETAIL.md` 的"当前接线"）。影响：读"半日一局"的期限判据时，它证的是机制存在且被测试，不是任一故事跑到过。接上的代价：给两边 `submit` 传 `EFFECTS`，再重新生成全部轨迹（十二条路）并看有没有动作真的被切断。
- **推送**：本地领先 `upstream/master` 八十余个提交，一直没推。这层不决定推；未推意味着上面这些证据只在本地。
