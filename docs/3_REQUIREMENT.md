# REQUIREMENT — 必须成立的事

这里只写"世界必须怎样"，不写怎么实现（那是 `6_ARCHITECTURE.md`），也不写它长什么样（`5_PRODUCT.md`）。

## EXPLICIT — 虚构契约

每个重要角色在虚构内是一个认真的自主的人：

- 追自己的目标，不为主角的成功服务；
- 从动机、需要、性格、能力、承诺与处境出发行动；
- 只知道他可能知道的事；
- 保留私下的信念，包括错的与不全的；
- 在人物设计允许时记得不准确；
- 因为人物自身的原因犯错，不因为剧情需要犯错；
- 该拒绝、无视、误解、竞争或反对主角时就那样做；
- 把世界当真，永不承认模拟、agent、提示词、路线或作者。

不许悄悄变笨、无理由合作、为好看而优化。主角没有叙事特权；世界只能通过显式机制、普通概率或行动挣来的后果帮到他。

## EXPLICIT — 作者写种子，世界跑种子

作者定义初始种子：地理、社会、历史、制度、技术、超自然规则；重要角色的完整背景、能力、关系、日程、需要与秘密；物件与信息的存在、归属、位置、可发现性与来源；绑在主角身上的那个系统及其能力、限制、任务规则、奖惩；一切对通常现实的显式例外。

初始化之后，模拟只从种子、角色策略、世界规则与记录下来的随机数前进。作者层可以看一局、可以在两次重放之间改种子，**不许悄悄修补当前这一局**。世界不许为了让路线推进而安排方便的盟友、巧合、情感转变或敌人的失误。

## EXPLICIT — 五层分离

客观世界状态、感知、信念、记忆、公开记录这五层必须分开。事件只能经世界 harness 改变客观现实；角色说的话是可观测的话语，不改变那句话的真假；听者靠自己决定信不信。

任何角色 agent 不得收到整份种子、别人的私密想法、隐藏路线信息、作者意图，或没有经过合法通道到达他的事实。

## EXPLICIT — 世界 harness 有权威

角色从不直接改世界，只提交意图；harness 校验、排程、结算、提交为事件。每一次被接受的状态变化都要有事件、有行动者或获授权的世界原因、有合法的因果链；被拒绝的意图不得改状态。

凡是显式规则能覆盖的事实（移动、可见、可闻、持有、钱、所有权、期限、约定、食谱、旅途耗时、睡眠、疲劳、饥饿、天气、受伤、消息送达），都由 harness 拥有，不由模型拥有。

## EXPLICIT — 时间与可选项

角色的推理不消耗模拟时间，动作消耗模拟时间。时间从世界规则或共同时刻表来，不由 agent 临时编一个方便的时长。长动作在合适时可以被打断；"至少连续睡六小时"是世界层的条件，不是承诺。

harness 生成**可供性**（这个角色在此刻有可能尝试什么），它只依赖位置、持有、可见的人与物、身心状态、技能与资源、已知承诺与期限、社交处境、显式前置条件、人物习惯与禁忌；不许依赖路线标签、想要的场景、恋爱目标或"是否好看"。可供性是一次尝试，不是保证的结果；"继续、停下、等着、离开、问清楚、什么都不做、尝试未建模的动作"永远可行。

## EXPLICIT — 原始项优先、通用工具禁止

日常动作应能不经 LLM 判定就执行：移动、观察、说话、听、读、发消息、处理物件、已知程序、吃饭睡觉工作学习等待、交易、约定、日程、期限。复合活动应能编译成原始步骤。

角色 agent 不得拥有不受限的、用于检查或操纵模拟的工具；它要新信息只能靠世界内的动作（看、听、问、找、读、打电话、回想、推断）。LLM 只用于有意义的决定、解释、计划与对话，不用于日常生活的每一秒。私下的思维链不是世界状态，不得当作权威事实。

## EXPLICIT — 确定性

在一个时间点上：世界先施加排程的确定事件；算出谁能感知；唤醒相关角色；生成各自的私有可选性与感知包；各 agent 从同一份世界快照独立提交意图；harness 用显式规则校验与消解冲突；被接受的意图成为事件或排程动作；时钟走到下一个唤醒点、完成点或世界事件。LLM 调用的完成顺序绝不许碰巧决定因果。

## EXPLICIT — 语义判定是有界的兜底

只有当一次提交的行动有"世界规则表达不出来的未定后果"时才调用语义判定。它只能回答"这次尝试可能造成什么"，不许推进剧情；不许发明无关事实、替无关角色决定、强迫好感/信任/原谅/合作、救或罚主角、覆盖权威状态、为好看而优化。它产出的非法效果由 harness 拒绝。

## EXPLICIT — 系统是有意的例外

主角在虚构内绑定一个真实的系统，它是唯一故意不理性的机制，其能力属于种子。它可以下发荒谬任务、透露超自然信息、跟踪条件、施加预定的奖惩，但必须服从固定的、可检查、可重放的规则。它约束普通行为，而不直接操纵别人的心智；它只能通过定义好的接口知道得比主角多。

## EXPLICIT — 可重放与证据

保留只追加的事件日志：种子与随机数标识、世界版本与时间、提交的意图与校验结果、被接受的事件与因果、投递出去的感知包、角色可见的消息、语义判定的请求与受限结果、系统任务与奖惩。下列断言必须可测：同一个种子与输入复现同一次运行；agent 用不到它知识之外的信息；每次状态变化都有获授权的原因；物理与社交前置条件被强制；被拒动作不改状态；情绪不因没有互动或定义过的内部过程而改变；主角没有隐藏的叙事偏好；语义判定不能造出它 schema 之外的效果。

## INFERRED — 非功能

- **零成本的回归**：任何结构判据都必须能在不花钱的情况下跑（MockProvider、脚本演员、种子副本）。
- **花钱要有授权**：provider 运行是一次被授权的支出；一次运行的花费记在它自己的记录里（`run.json → spend`），到上限即停，不许悄悄再跑一次。
- **确定性可复现**：同一代码同一输入逐字节一致；生成的工件要能与提交一致地重跑出来。
- **不可复核即不存在**：任何声明若不指向一件在工作树或 git 里的工件，等于没发生过。
- **凭证不进仓库**：只写名字或占位符。

## INFERRED — 约束

Python 3 标准库 + `PyYAML`；轨迹打包用 `zstd`；模型经本地 LiteLLM 代理提供（模型名与价格随运行记在该次运行的记录里）。单机、单用户、无联网游戏客户端、无图形界面。
