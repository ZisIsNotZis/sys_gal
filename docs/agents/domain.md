# Domain docs

This repository uses the single-context layout. Before exploring a domain area, read `CONTEXT.md` at the repository root if it exists, then read relevant decisions under `docs/adr/`. These files may be created lazily when domain terms or architectural decisions become settled.

Use the glossary vocabulary from `CONTEXT.md` in issue titles, proposals, and tests. If an existing ADR conflicts with a proposed change, call out the conflict explicitly instead of silently overriding it.

Expected layout:

```
/
├── CONTEXT.md
└── docs/adr/
```
