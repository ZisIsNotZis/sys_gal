# GOAL — 成功长什么样

## EXPLICIT

八级里程碑是这类目标的一次落地，全部经人批准（人确认"全部五项 OK，开工 M0"，assent: agreed）。路线与状态见 `0_ROADMAP.md`。里程碑是用户同步点，内部工作包不必逐个同步。

## CONFIRMED

一条弧线（12 个模拟日的中文校园故事，**《契约失效时请勿喂猫》**）在库上跑完，2013 年那份通知书上的签字由人自己说出来、绝不由台账剧透。这是最后一级；它前面六级各换一个世界，每一级都必须自己站得住。

## INFERRED

成功由四类可观测的事组成，缺一类都不算：

1. **可读**：一支陌生读者能从头读到尾，说出"他们在争什么"，并指出至少一处他没想到的走向。
2. **可复核**：每条判据都有一条命令，命令的输出就是判据本身；反过来，任何一条判据在坏掉时都有东西变红（反向控制），否则那条判据不算存在。
3. **通用**：同一套概念在两个完全不同的世界都成立，且没有孤儿概念（每个进库的概念至少被两支故事用到）。一个概念只在一个世界里成立，它就是那个世界的方言。
4. **被世界推动**：一局的走向能由角色当时的上下文推出来，作者写进去的只有条件与限制；`[角色]` 的动作能追溯到它当时的上下文。

**不是成功的样子**：一条能跑但读起来像作者安排的路；一套全绿但抓不住任何错的门；一个"跨过了午夜"却没有夜的世界；一个数由剧本写死而盘点照样通过的实验。

## 不宣称

不宣称模拟出来的角色在人类意义上像人。所有判据证明的是模型一致性、因果完整性与信息纪律，不是人类级故事质量。
